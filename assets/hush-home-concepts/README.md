# Hush Home concepts

These are visual proposals, generated with the built-in imagegen tool. The Home redesign and pause sheet have not been implemented yet.

| File | Prompt direction |
| --- | --- |
| `home-light-centered.png` | Warm paper Home with a centered breathing invitation, library shortcuts, and bottom Search. |
| `home-dark-search-first.png` | Dark pine Home with a small pause row near the shortcuts and bottom Search. |
| `home-light-balanced.png` | Warm paper Home with a compact pause row in the lower middle, shortcuts, and a stronger bottom Search. |
| `pause-sheet-breathe.png` | On-demand Breathe sheet with technique, duration, sound, and Start. |
| `pause-sheet-meditate.png` | On-demand Meditate sheet with a quiet timer, duration, sound, and Start. |

Shared constraints in the prompts: no recent searches or video history on Home, no content feed, no autoplay, and no PipePipe visual elements. History remains reachable through its shortcut. The meditation proposal is a local quiet timer with optional start and end chimes; it does not assume a guided audio library.
